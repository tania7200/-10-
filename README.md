# 그레이드원 대치10관 수학학원 홈페이지

대치동 최상위권 수학 전문, 그레이드원 대치10관의 공식 홈페이지입니다.

## 주요 기능
- **1:1 개별맞춤 시스템 소개**: 대치동식 밀착 케어 및 오답 역추적 시스템 안내
- **원장 소개**: 이선규 대표원장의 약력 및 지도 실적
- **공지 & 입시 자료실**: 최신 교육 뉴스 및 입시 자료 열람
- **1:1 상담 예약**: Formspree를 연동한 실시간 상담 신청 및 관리자 CMS
- **반응형 디자인**: PC 및 모바일 최적화 레이아웃

## 기술 스택
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Animations**: Motion
- **Backend/Forms**: Formspree API (상담 예약 수집)

## 실행 방법

### 개발 모드
```bash
npm install
npm run dev
```

### 빌드 및 배포
```bash
npm run build
```
